Flask Error Handling

A complete demo of HTTP error codes, custom exceptions, and error handler patterns.

4xx — Client Errors

400 Bad Request Malformed or unreadable request body 401 Unauthorized Authentication required 403 Forbidden Insufficient permissions 404 Not Found Resource does not exist 405 Method Not Allowed Wrong HTTP verb 422 Validation Error Input validation failure 429 Too Many Requests Rate limit exceeded

5xx — Server Errors

500 Internal Server Error Unhandled exception on the server 503 Service Unavailable Downstream dependency down

JSON API — Accept: application/json

404 API Not Found Returns JSON instead of HTML

How it works

# app/exceptions.py
class NotFoundError(AppError):
    status_code = 404
    message = "The requested resource was not found."

# app/errors/__init__.py
@app.errorhandler(AppError)
def handle_app_error(error):
    if wants_json(request):
        return jsonify(error.to_dict()), error.status_code
    return render_template("error.html", ...), error.status_code
