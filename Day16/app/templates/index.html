Task API (HTTP Methods)

This app uses a clean Flask structure and demonstrates proper HTTP method usage.

Endpoints

  • GET /api/tasks - List all tasks
  • GET /api/tasks/<id> - Get one task
  • POST /api/tasks - Create a task
  • PUT /api/tasks/<id> - Update a task
  • DELETE /api/tasks/<id> - Delete a task

Quick test with curl

curl -X POST http://127.0.0.1:5000/api/tasks -H "Content-Type: application/json" -d '{"title":"Learn HTTP"}'
